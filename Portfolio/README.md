# Sri Ranga Sai Potturi — Portfolio

A responsive personal portfolio website for a third-year Computer Science and Engineering student specializing in AI and Machine Learning.

## Files
- `index.html` — page structure and content
- `style.css` — dark responsive styling
- `script.js` — mobile navigation and current year
- `assets/profile.jpg` — add your own profile photograph here

## Run locally
Open `index.html` in your browser. In VS Code, you can also use the Live Server extension.

## Publish with GitHub Pages
1. Create a **public** repository named `portfolio` in your GitHub account.
2. Upload all files and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait a few minutes. Your site should be available at `https://YOUR-USERNAME.github.io/portfolio/`.

## Before sharing
- Add your own portrait as `assets/profile.jpg` (JPG format recommended).
- Replace the project links with each project's actual repository or live demo URL.
- Check that project descriptions and listed technologies match your implementation.
- Add only verified certificates, awards, and achievements.
- If you want a resume button, put your PDF in `assets/` and add a link to it in `index.html`.
